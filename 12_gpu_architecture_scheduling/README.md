launch configuration fast or slow.

## What this session covers

- **Architecture:** a GPU is an array of streaming multiprocessors (SMs), grouped into GPCs;
  each SM has streaming processors, control logic and on-chip memory; global memory is
  off-chip DRAM.
- **Block scheduling:** blocks are assigned to SMs whole, a few at a time; freed slots are
  refilled from the grid.
- **Barriers:** `__syncthreads()` and its rule (all threads of the block or none), barrier
  scope, and why blocks may not wait for each other: transparent scalability, waves and the
  tail effect.
- **Warps and SIMD:** blocks are cut into warps of 32 consecutive threads (row-major for
  2D/3D blocks); a processing block issues one instruction for a whole warp (SIMT).
- **Control divergence:** if/else and loops inside a warp, boundary checks in 1D and 2D,
  independent thread scheduling and `__syncwarp()`.
- **Latency tolerance:** many resident warps, zero-overhead switching.
- **Occupancy:** threads, block slots and registers per SM, performance cliffs, and the
  device-query API.
