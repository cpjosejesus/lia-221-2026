# Intro — From threads to massively parallel (start here for sessions 08–10)

A short deck to open the second block of the course. It recaps folders `01`–`07` in one
table, explains what changes in sessions `08`–`10` (from "is it safe?" to "is it faster, and
by how much?"), introduces **data parallelism** with the classic colour-to-grayscale
example, and previews the destination: the CUDA program model (host and device, kernels,
grid/blocks/threads, `cudaMalloc`/`cudaMemcpy`, launch configuration, `nvcc`), with warm-up
questions and answers.

Open [`slides.html`](slides.html) in a browser; arrow keys or space to navigate, `p` to
print. The last slide links to the session-08 deck.

Reading that goes with it: Kirk & Hwu, *Programming Massively Parallel Processors*,
chapter 2.
